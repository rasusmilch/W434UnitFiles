# ZIFOpenAll

## Declaration

```ats
function ZIFOpenAll(): void;
```

## Call pattern

```ats
ZIFOpenAll();
```

## Description

With this function all ZIF modules can be opened. If the ZIF modules are open the connectors can be removed from the test system.
